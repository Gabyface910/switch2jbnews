History & Breakthroughs

Beginnings

Shortly after Nintendo released the Switch 2 in June 2025, crafty community members discovered a game save exploit. While it functioned well as a proof of concept, it fell short of a full hack. Months of relative quiet followed, punctuated by skeptical community forum threads claiming the console would never be breached.

Getting Closer

In July 2026, developer Gezine—widely recognized for creating the PS5 Y2JB (YouTube Jailbreak)—shared a breakthrough on X showcasing a custom system error code handler.

"I created a Switch 1/2 userland exploit that is not a WebKit or save exploit."

"But we already have a userland exploit from day one"

"The difference is that the existing userland exploit is based on the save exploit, which can't be used without save transfer using the Nintendo Online Service, which forces you to be on the latest firmware."

"So even if a kexploit or some software-based privilege escalation is found, 99% of people can't use the save exploit. But this one works without any restrictions and works on all firmware."

"Why not hack WebKit? Switch 2 WebKit has ARM PAC (Pointer Authentication Code), which prevents ROP code execution. So I avoided it, as there was an easier way to exploit it."

— Gezine

ns2jb Exploit

The homebrew floodgates blew open on October 22, 2026, when Sammy Hajhamid (commonly known as pepsipu) dropped a software modification framework called ns2jb. This tethered softmod requires user interaction via the software SmileBASIC 4, manual runtime inputs, and a custom NodeJS payload injector running via an external host interface device.

The jailbreak currently lacks coldboot persistence. To prove its structural validity, pepsipu published custom code patches injecting external community characters into Mario Kart World.

Ecosystem Responses

Nintendo

Within 7 hours of public disclosure, Nintendo pulled SmileBASIC 4 directly from the global eShop infrastructure. While early enthusiasts bypassed the delisting by navigating through the console's internal software update news channels to force an entitlement download, Nintendo has completely patched that avenue. They are aggressively engineering structural firmware revisions.

WebKit Frontiers

Following private beta implementations, pepsipu has successfully backported the core ns2jb logic payload over to the console's integrated WebKit browser subsystem, rendering it widely accessible without reliance on the original target software.
